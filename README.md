# myPokédex

A modern, interactive Pokémon collection app built with React and the PokéAPI.

🔗 **[Live Demo](https://nortonrd3.github.io/mypokedex/)**

## Features

- 🔍 **Search & Discover** - Search for any Pokémon or browse random selections
- 📦 **Personal Collection** - Add your favorite Pokémon to your collection
- ❤️ **Like System** - Mark your favorites with likes and filter by them
- 🔐 **Authentication** - Sign up/sign in to manage your collection (simulated)
- 📱 **Responsive Design** - Works seamlessly on desktop, tablet, and mobile
- 🎨 **Beautiful UI** - Gradient designs with smooth animations and hover effects

## Tech Stack

- **React** - UI library
- **React Router** - Client-side routing with protected routes
- **PokéAPI** - Pokémon data source
- **Vite** - Build tool and dev server
- **CSS3** - Custom styling with modern features

## Features in Detail

### Authentication (Simulated)

- User registration and login with email/password
- Token-based session persistence
- Protected routes for collection page

### Pokémon Collection

- Add/remove Pokémon from your personal collection
- Like/unlike Pokémon
- Filter collection by liked Pokémon
- Search within your collection

### UI/UX

- Smooth animations and transitions
- Responsive grid layouts (2-6 columns based on screen size)
- Type-based color coding
- Loading states with custom spinner
